# Website fonts

Cinzel (Natanael Gama) provides Roman inscription-style headings. EB Garamond (Georg Duffner and Octavio Pardo) provides the reading text. Both are self-hosted Latin WOFF2 subsets distributed by Google Fonts under the SIL Open Font License 1.1. Their individual copyright notices and licences accompany these files. They are third-party fonts, outside the project MIT and original-artwork CC BY terms.

Upstream sources: [Cinzel](https://github.com/google/fonts/tree/main/ofl/cinzel), [EB Garamond](https://github.com/google/fonts/tree/main/ofl/ebgaramond).

- cinzel-latin.woff2: https://fonts.gstatic.com/s/cinzel/v26/8vIJ7ww63mVu7gt79mT7.woff2
- eb-garamond-latin.woff2: https://fonts.gstatic.com/s/ebgaramond/v33/SlGUmQSNjdsmc35JDF1K5GR1SDk.woff2
