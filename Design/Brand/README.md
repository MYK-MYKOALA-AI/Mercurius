# Mercurius mark

The original mark depicts Mercury in a winged helmet within a bronze coin. It was generated with an image tool and then resized into application icons. It is a raster PNG, not a vector master. Embedded provenance metadata was removed from the public copy without changing its compressed pixel payload.

Rebuild `Resources/AppIcon.icns` with `sh scripts/make-icon.sh`. The code uses MIT; the original mark and generated icons use CC BY 4.0. See `LICENSE-ARTWORK.md` for credit and trademark terms. Koa remains the separate in-app mascot.
