# Security

Do not post credentials, transcripts, recordings or exploitable security details in a public issue. Use this repository's private vulnerability reporting feature when available. If it is unavailable, contact MyKoala through [mykoala.com.au](https://mykoala.com.au/) and ask for a private reporting channel before sending sensitive details. There is no promised response deadline.

This is a source preview under validation. There is no verified public installer or production security certification. Treat microphone, Accessibility, browser automation, local history and API access as sensitive permissions. Grant only what you use.

API keys are supplied by each user and stored in the macOS Keychain after explicit Save. On-device speech with cloud cleanup off keeps audio/text local; cloud speech sends audio to the selected provider, and optional cloud cleanup sends transcript/context to OpenRouter. Provider data retention, free-model terms and charges apply separately.

The publication check scans for common credential formats and private files. It cannot prove the absence of every secret. If a real credential is exposed, notify its owner privately and revoke or rotate it with the owner's authorization; deleting a public file does not remove prior copies.
